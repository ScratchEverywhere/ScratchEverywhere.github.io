# Introduction

Scratch Everywhere! **(note the exclamation mark)** is a cross-platform
implementation of the Scratch runtime. In simpler words, it's a way to run
Scratch projects on old homebrew consoles.

The project supports GameCube, DS, Wii, DSi, 3DS, Wii U, Switch, PSP, Vita, PS4,
webOS (for LG TVs), Original Xbox, Windows, macOS, Linux/BSD, Libretro
(RetroArch), and WebAssembly (for browsers)!
